# 快速上手

**AI 跑通的，Amber 封存。**

Amber 把你和 AI 助手（agent）一起跑通的一次操作，固化成一个**应用**。以后随时一键执行，执行时不再经过 AI，每次结果都可预期。

这一页带你在 5 分钟里走完一遍：从和 agent 跑通一件事，到它变成一个随时能用的应用。想先看操作演示，可以看[视频手册](https://xu4wang.github.io/amber-manual/)，按章节观看，每章 1 分钟左右。

## 开始之前

- 你的 agent（比如飞书里的 botmux 机器人）已经装好了 `amber` 命令和 Amber 的 skill。没装的话请部署方按 [agent 接入](cli-and-skill.md) 装上。
- Amber 机器人在你所在的群里，或者你能和它私聊。

## 第一步：和 agent 把事情跑通

像平常一样让 agent 做事，比如：

> 帮我查一下近 7 天的注册商户数，按天画个柱状图。

确认结果是对的，再进入下一步。

## 第二步：让 agent 存进 Amber

对 agent 说：

> 把刚才这个存进 Amber，叫「注册商户数」，天数做成参数。

agent 会把刚才的操作写成一段脚本，提交给 Amber。可以顺便说明：

- 哪些地方要做成**参数**（每次执行时填，比如「天数」）；
- 哪些值每次都一样、不该让执行的人改，做成**配置项**（比如要查的区域）；
- 要用到某个系统的 token 时，会声明一个**密钥**（只写名字，值你之后自己填）。

应用**默认允许定时执行**，不需要的话跟 agent 说「不要定时」。

## 第三步：认领、试运行、提交审核

Amber 会在当前的群或私聊里发一张**认领卡**，上面有代码和说明：

1. 点「**试运行**」：Amber 以你的身份真实执行一次。有参数的话先在卡片上填好；需要密钥的，先点「设置密钥」，在私聊里填好。
2. 结果没问题，点「**提交审核**」。认领的人就是这个应用的**创建人**。
3. 不认识、不需要的草稿，点「**丢弃**」。

## 第四步：等审核通过

审核人会在飞书「审批」里收到待办，在飞书知识库里能看到完整代码和试运行结果。**所有审核人都同意**后，应用生效，认领卡变成「已生效」。

## 第五步：用起来

- 在群里 @Amber 发「**注册商户数 30**」，或者发「**帮助**」从列表里选。
- 让 agent 帮你跑：「帮我跑一下注册商户数，最近 30 天」。
- 在网站上执行、看历史结果：在飞书私聊 Amber 发「**登录**」。
- 定时执行：对 agent 说「每个工作日早上 9 点帮我跑一下注册商户数」，点确认卡上的「创建定时任务」。

应用**只有你自己看得见、能执行**。想给同事用，见[应用的分享](sharing.md)。
