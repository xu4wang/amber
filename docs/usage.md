# 使用指南

Amber 能把你和 AI 助手（agent）一起跑通的一次操作，固化成一条**指令**。以后随时一键执行，执行时不再经过 AI，每次结果都可预期。

本文写给使用 Amber 的人，不需要任何技术背景。

## 1. 几个概念

| 概念 | 说明 |
|---|---|
| 指令 | 一段审核过的脚本，加上它需要的参数，比如「天气」带一个「城市」参数。指令只能由审核通过的那一版代码执行，代码一改就要重新审核 |
| 范围 | 指令属于创建它的群或私聊。群指令只有群成员能用，私聊指令只有你自己能用。管理员可以把指令设为「全局」，让所有地方都能用 |
| 定时任务 | 让一条指令按时间自动执行，比如「工作日 09:00」。每次都以创建人的身份执行 |
| 执行身份 | 指令总是以「点按钮的那个人」的身份执行。查数据时，你能看到的就是你本人有权限看的数据 |

## 2. 把一次操作固化成指令

1. 在飞书里和你的 agent 把事情做成，比如「查一下近 7 天的注册商户数并画图」。
2. 对 agent 说：「**把刚才这个存进 Amber，叫『注册商户数』**」。可以顺便说明哪些地方要做成参数，比如「天数可以改」，以及要不要允许定时执行。
3. Amber 会在当前的群或私聊里发一张**认领卡**。认领卡上有代码和说明：
   - 点「**试运行**」，Amber 会以你的身份真实执行一次。有参数的话，先在卡片上填好。
   - 结果没问题就点「**提交审核**」。认领的人就是这条指令的创建人。
   - 不认识、不需要的草稿，直接点「**丢弃**」。
4. 审核人会在飞书「审批」里收到待办，在飞书知识库里能看到完整代码和试运行结果。**所有审核人都同意**后，指令生效，认领卡也会变成「已生效」。

## 3. 执行指令

### 在飞书里

- 私聊 Amber，或者在群里 @Amber，发「**帮助**」，会列出这里能用的指令，点「选择」后填参数执行。
- 直接发指令名和参数也可以，比如「天气 上海」。
- 结果会直接更新在卡片上：表格显示成表格，折线图和柱状图显示成飞书图表。
- 标着「**需确认**」的指令会改数据或有风险，一定要从表单里点红色的「确认执行」才会执行。

### 让 agent 帮你执行

直接跟你的 agent 说「帮我跑一下注册商户数，最近 30 天」：

- 不涉及个人权限的指令，agent 会直接执行，再把结果告诉你。
- 需要用你的身份，或者需要确认的指令，Amber 会在当前对话里发一张**确认卡片**。你点「执行」之后才会执行，结果同时显示在卡片上和 agent 的回复里。
- 卡片上只有被请求的人能点。不是你发起的请求，不要点。

### 在网站上

1. 登录：在飞书**私聊** Amber，发送「**登录**」，点卡片上的「打开 Amber 网站」。这个链接 5 分钟内有效、只能用一次，**不要转发给别人**。
2. 左边是指令树，按「我的私聊 / 各个群 / 全局指令」分组。选中一条指令后：
   - 「执行」页：填参数后执行，结果显示在下方。
   - 「定时」页：创建定时任务。只有允许定时的指令才有这一页。
   - 「代码」页：查看审核通过、实际在运行的代码、第几版和历史版本，以及审核文档链接。
   - 页面底部的「管理」：你是创建人（或管理员）时，可以在这里下线指令。
3. 「最近运行」里有你在所有渠道（飞书、网站、agent、定时）的执行记录，可以随时回看输出。
4. 不用时点右上角「退出」。如果怀疑别人用了你的登录，在飞书私聊 Amber 发「**退出网站**」，所有浏览器里的登录都会失效。

## 4. 定时任务

- 只有审核时允许定时的指令才能定时执行。
- 两种创建方式：在网站上指令的「定时」页填写；或者对 agent 说「每个工作日早上 9 点帮我跑一下注册商户数」，然后点它发来的确认卡片。
- 时间写法：

| 写法 | 例子 |
|---|---|
| 每天、工作日、每周几的固定时间 | 每天 09:00、工作日 18:30、每周一 08:45 |
| 每隔几小时 | 每小时、每 2 小时、每 2 小时 15 分 |
| 每隔几分钟（最短 5 分钟） | 每 5 分钟、每 15 分钟、每 30 分钟 |

- 时间按 Amber 服务器设定的时区计算，可以选的时区以网站上的下拉框为准。确认卡片和网站上都会写明是哪个时区。
- 结果发到飞书：群指令发到原来的群或话题，私聊和全局指令发到你和 Amber 的私聊。**脚本没有输出时不发消息**，所以「有异常才提醒」这类监控，正常时就不会打扰你。
- 失败时只私聊通知创建人。连续失败 3 次会自动暂停。指令下线、换了新版本、你退出了那个群时，定时任务也会自动暂停。
- 在网站上可以暂停、恢复、立即运行一次或删除自己的定时任务。在飞书里 @Amber 发「定时任务」也能看到列表。

## 5. 常见问题

**为什么要认领和审核？**
指令是 AI 写的代码，可能会改数据，也可能会访问外部系统。认领确保有人对它负责；审核确保有人看过代码。审核通过后代码就锁定了，以后每次执行跑的都是同一份代码。

**为什么有时要点确认卡片，有时不用？**
agent 没法向 Amber 证明它是在替谁做事。所以凡是要用你的身份（比如按你的权限查数据），或者开了「执行前确认」的指令，都必须由你本人在飞书里点一下。不涉及任何人权限的指令，agent 可以直接执行。

**卡片上写的「你的 agent」是谁？**
是帮你提交或发起请求的 AI 助手。agent 没报名字时就显示「你的 agent」。

**我看不到某个群里的指令？**
网站只显示你所在群的指令。如果你确实在群里却看不到，请联系管理员确认 Amber 有读取群成员的权限。

**指令想改怎么办？**
跟 agent 说要改什么，它会用同一个名字提交新版本。认领卡和审核文档里会标明「新版本」，并列出和当前版本的代码差异。新版本只能由原创建人（或管理员）认领，审核通过后自动替换旧版本。挂在旧版本上的定时任务会先暂停，Amber 私聊创建人一张卡片，点「换绑到新版本」就会继续运行，参数和时间都不变。

**不需要的指令怎么下线？**
创建人或管理员可以在网站上指令页面底部点「下线这条指令」，或者在飞书里对 Amber 说「下线 指令名」。下线后不能再执行，它的定时任务会暂停并通知创建人。
