# 页面应用

页面应用是一个网页：agent 按你的要求写好页面，发布到 Amber，就像放到 demo 网站一样马上能打开。和普通网页不同的是，页面里可以通过 Amber 查数仓、读机器人台账、写飞书，用的都是审核过的 Amber 应用，以打开页面的人自己的身份执行。

## 做一个页面

跟自己的 agent 说要什么样的页面，比如：

> 做一个页面：选天数，查各城市的注册商户数，显示表格和柱状图。用 Amber 的「注册商户数」应用拿数据，发布到 Amber。

agent 会：

1. 写一个目录：`index.html`，加上样式、脚本、图片等。样式完全由它自己决定
2. 在目录里放一个 `amber.json`，写明页面要调用哪些应用：`{"apps": ["注册商户数"]}`。页面需要的应用还没有，agent 会顺手写一个提交审核，审核一次以后反复用
3. 运行 `amber page publish ./目录 --name shanghu`，发布到 Amber

第一次发布时，群里出现一张卡片，列出页面会调用的应用，并附上页面首屏的截图。**你点「确认发布」**后页面才生效，卡片上会出现「打开页面」和「私聊我免登录链接」两个按钮。

之后改页面，跟 agent 说要改哪里，它重新发布，**马上生效，不用再确认**，刷新页面就能看到。只有页面要调用的应用变了（`amber.json` 改了），才会再出一张确认卡片。

页面本身不用审核：它只能调用你确认过的那几个应用，而这些应用都审核过，见下面「为什么页面不用审核」。

## 打开页面

- 飞书卡片上点「打开页面」，或者在网站左侧找到页面（挂在它所在的群下面，带「页面」标），点「打开页面」，都会新开一个标签页
- 要先登录 Amber 网站，登录一次能用 7 天。还没登录时，在卡片上点「私聊我免登录链接」：Amber 在你和它的私聊里发一个链接，点开就登录并打开页面。链接 5 分钟内有效、只能用一次，只发给有权限打开这个页面的人，不会出现在群里。也可以私聊 Amber 发「登录」
- 页面里每次查询都以你自己的身份执行：查数仓按你自己的权限出数；会改数据的应用，Amber 会先弹出自己的确认框，你点确认才执行
- 每次调用都会进「最近运行」和审计日志，受运行时限和并发上限约束

## 谁能打开

页面属于创建人。在网站上打开这个页面，「谁能访问」里可以选：

| 选项 | 谁能打开 |
|---|---|
| 仅我（默认） | 只有你自己 |
| 群里所有人 | 页面所在群里的所有人 |
| 指定的群成员 | 你勾选的人 |

每次打开、每次调用都会检查：在名单里，并且现在还在这个群里。退群的人自动失去访问权限。私聊里的页面只有创建人能打开。

**管理员可以打开任何页面**（排查问题、检查内容用），不受上面的设置限制：页面里的应用以管理员自己的身份执行，用到你的密钥的应用照样只有你能调用。管理员不能改谁能访问。管理员打开没有分享给他的页面时，每次都记审计（`page.admin_open`）。

**别人通过你的页面调用应用时，以他自己的身份执行**。也就是说，你自己的应用可以借页面给群里指定的人用，不用上架或复制。两类应用要注意：

- **用到密钥的应用**：别人用会用到你的凭证（比如你的 token），所以只有你自己打开页面时能调用，别人调用会被拒绝
- **在执行端环境里运行的应用**：别人会在那个环境里执行，能读到那个环境里的数据。设置访问范围时页面上会提醒

## 为什么页面不用审核

页面在一个隔离的框里运行，放在单独的域名下：

- 不能访问网络，也不能跳转到别的网站、弹出新窗口、加载外部图片
- 只能通过 Amber 调用 `amber.json` 里、并且你确认过的应用，以打开页面的人的身份执行
- 打开飞书文档这类链接要用 `Amber.open`，只能打开网络白名单里的地址（默认是飞书）

所以页面写得怎么样，打开它的人能看到的数据也不会超过他自己能查到的，数据也传不出这个页面。会改数据的操作一定要他本人在 Amber 的确认框里点。

## 给写页面的 agent

在页面里加载 Amber 的接口：

```html
<script src="/sdk/amber-page.js"></script>
```

| 接口 | 作用 |
|---|---|
| `await Amber.run('应用名', { 参数: '值' })` | 调用应用，返回 `{ markdown, blocks, json, runId, elapsedMs }` |
| `await Amber.render(元素, 结果)` | 把结果画成和飞书卡片一样：文字、表格、图表 |
| `await Amber.open(链接)` | 在新标签页打开白名单里的地址（默认是飞书） |
| `await Amber.me()` | `{ name, page }`：打开页面的人的名字和页面名 |
| `Amber.quiet = true` | 不显示 Amber 的「正在执行」提示，由页面自己显示 |
| `await Amber.embed(元素, 'key', { height, tools })` | 嵌入方：把 `amber.json` 里 `embeds` 的这一项画进元素（没有权限时显示提示）。不写 `height` 时高度跟着内容走。`tools` 可以往左侧图标里加自己的操作：`[{ icon: '<svg…>', title: '导出', onClick(h) {…} }]` |
| `Amber.setParams({ 参数: 值 })` | 嵌入方：更新共享参数，嵌入的模块按 `params` 的对应关系收到新参数（写了 `"follow": false` 的除外） |
| `Amber.setFilter({ 字段: 值 })` | 设置联动筛选（值为 `null` 去掉这个字段，`setFilter(null)` 全部清掉），传给打开了「点击联动」、并且声明接收这个字段的模块 |
| `Amber.onFilter(fn)` | 联动筛选变化时调用 `fn(filter)`：嵌入方收到本页和各模块发出的；被嵌页面收到嵌入方传来的 |
| `Amber.filterBar(元素, { 字段: '显示名' })` | 嵌入方：有联动筛选时在元素里显示「联动筛选：区域=泰国 ×」，点 × 取消 |
| `Amber.embedded` | 被嵌页面：现在是不是嵌在别的页面里 |
| `Amber.onParams(fn)` | 被嵌页面：`fn(params, { follow })`。跟随时 `params` 是嵌入方传来的参数；不跟随时是 `null`，页面显示自己的参数控件。加载过程中就可能收到，`fn` 用到的变量和函数要先定义好，最好在脚本最后注册 |
| `Amber.emit({ 字段: 值 })` | 被嵌页面：发出联动（只传 `embeddable.emit` 里声明的字段）。不在嵌入状态时返回 `false` |
| `Amber.onExport(fn)` | 被嵌页面：「导出 Excel」时调用 `fn()`，返回 `{ name, columns: [{ name, label }], rows }`（多张表用 `{ sheets: [...] }`）。不注册时导出页面里的表格（`<table>`）|
| `Amber.exportExcel('文件名', 数据)` | 任何页面：把数据下载成 .xlsx，数据格式同上。页面自己的报表也可以用它做导出按钮 |
| 空白处点击 | 被嵌页面里点到空白处时，嵌入方显示左侧工具图标。链接、按钮、表单控件和设置了 `onclick` 的元素不算空白；用别的方式处理点击的元素加上 `data-amber-action` 属性 |

`blocks` 是拆开的输出：`{kind: 'markdown', text}`、`{kind: 'table', data}`（列和行）、`{kind: 'chart', data}`（vega-lite）、`{kind: 'json', data}`。应用可以多输出一个 ` ```json ` 块专门给页面用，页面拿到的 `json` 就是它；飞书卡片和网站上不显示这一块。

限制：

- 文件：最多 200 个、共 10MB；只能是常见的静态文件（html、css、js、json、图片、字体、csv 等），不能有点开头的文件
- 不能从外部 CDN 加载库：要用的库放进目录一起发布。Amber 提供 `/vendor/marked.min.js`、`/vendor/purify.min.js`、`/vendor/vega.min.js`、`/vendor/vega-lite.min.js`、`/vendor/vega-embed.min.js`
- 页面不能直接请求外部接口，数据一律通过 `Amber.run` 拿；可以读目录里自己的文件（比如 `fetch('data.json')`）
- 可以让浏览器下载页面自己生成的文件（比如导出 CSV）

## 嵌入其他页面

一个页面可以把别的页面嵌进来，比如在「上账提现总览」里嵌「贸易订单看板」和「商户排行」。被嵌的页面照常独立发布、独立设置谁能访问，嵌进来后：

- **工具图标**：嵌入的模块不加标题栏，和页面自己的内容一样整洁。点一下模块的空白处，模块左侧竖着出现几个图标：「点击联动」开关、「打开原页面」（鼠标停在上面能看到来自哪个页面、谁维护）、「导出 Excel」（把这个报表当前的数据下载成 .xlsx）。点页面别处图标就收起。以后加的操作也放在这里。
- **参数跟随**：嵌入方页面顶部的参数（日期、币种等）会传给嵌入的模块，模块跟着变，不用另外操作。个别模块不想跟随时，嵌入方在 `amber.json` 里给它写 `"follow": false`，它就显示自己的参数。
- **点击联动**：点嵌入方页面的柱子或表格的行，或者点嵌入模块里的柱子、行，所有打开了「点击联动」的模块一起按这个字段筛选，再点一次取消。查看的人可以用左侧的「点击联动」图标关掉某个模块的联动，只影响他自己。
- **没有权限的模块**：打开页面的人没有某个被嵌页面的访问权限时，那一块显示无权限提示，页面的其它部分照常显示。
- **数据仍然按各自的规则拿**：被嵌页面只能调用它自己 `amber.json` 里的应用，以打开页面的人的身份执行，和单独打开它时一样。

两边都要在 `amber.json` 里写清楚：

被嵌的页面声明允许被嵌入，以及接收哪些参数、接收和发出哪些联动字段。没写 `embeddable` 的页面不能被嵌：

```json
{
  "apps": ["贸易订单数"],
  "embeddable": {"title": "月贸易订单数", "params": ["range", "cur"], "receive": ["region"], "emit": ["merchant"]}
}
```

嵌入方列出嵌哪些页面。`page` 写页面 id（打开页面时地址里 `/p/` 后面那 8 位），同一个会话里的页面也可以直接写页面名。`params` 写成 `{"被嵌页面的参数": "本页的参数"}`，`receive` / `emit` 表示接不接收、发不发出联动（默认都不开）。`follow: false` 表示参数默认不跟随：

```json
{
  "embeds": [
    {"key": "trade", "page": "trade-orders", "params": {"range": "range", "cur": "cur"}, "receive": true},
    {"key": "rank", "page": "a1b2c3d4", "params": {"range": "range"}, "receive": true, "emit": true}
  ]
}
```

最终生效的是两边都允许的部分：参数只传被嵌页面声明过的，联动只传它声明过的字段。`embeds` 一改，和改应用一样要在飞书卡片上确认发布；确认时会检查每个被嵌页面都存在、允许被嵌入，而且确认的人自己能打开它。被嵌页面去掉 `embeddable` 后马上生效，嵌入它的页面那一块会显示「不再允许被嵌入」。

**安全上要知道的一点**：所有页面都放在同一个页面域名下，嵌入方页面的脚本读得到嵌入模块里显示的内容。这不会多泄露数据：嵌入模块里的数据本来就是打开页面的人自己能看到的，页面也传不出网络。被嵌页面里会改数据的应用，执行前照样由 Amber 弹出确认框。

## 页面设计规范

目标是页面干净整洁：该有的功能都有，不需要的东西一律不加。写页面的 agent 按这几条做：

- **不写说明性文字**：不放操作提示（「点柱子可以筛选」）、数据来源、维护人、「演示数据」之类的说明，也不加「本页」「主页面」这类装饰标签。标题、图例、坐标轴、列名这些读数据必需的东西保留。
- **图表不加多余元素**：不显示最大值、角标这类没人看的数字，只保留读懂图所需的图例和坐标。
- **数据多就分页**：表格超过一屏时分页显示，带页码和「跳至第几页」，不要一次全列出来。
- **次要操作收起来**：联动开关、打开原页面、导出这类不常用的操作放进点击后才出现的图标栏，不常驻在页面上。
- **不让页面跳动**：筛选状态不单独显示成一条会出现、消失的提示，再点一次同一个元素就取消。
- **点得准**：按钮和可点区域足够大（至少 30px 见方），图标意思一眼能看懂（下载就用下载箭头）。
- **跳转留退路**：从汇总页进到明细页，在同一个标签页打开，并提供返回。

## 使用情况

创建人在网站上打开自己的页面，「使用情况」里能看到调用了多少次（成功、失败各多少）、谁调用过、最近 30 次调用的结果，以及谁打开过页面。同一个人 30 分钟内反复打开只算一次。被分享的人看不到这些。管理员能看到所有页面的使用情况（见[管理员手册](admin.md)）。

## 删除

创建人或管理员可以在网站上删除页面，链接立即失效，文件一起删除，应用不受影响。
