# 页面应用

页面应用是一个网页：agent 按你的要求写好页面，发布到 Amber，就像放到 demo 网站一样马上能打开。和普通网页不同的是，页面里可以通过 Amber 查数仓、读机器人台账、写飞书，用的都是审核过的 Amber 应用，以打开页面的人自己的身份执行。

## 做一个页面

跟自己的 agent 说要什么样的页面，比如：

> 做一个页面：选天数，查各城市的注册商户数，显示表格和柱状图。用 Amber 的「注册商户数」应用拿数据，发布到 Amber。

agent 会：

1. 写一个目录：`index.html`，加上样式、脚本、图片等。样式完全由它自己决定
2. 在目录里放一个 `amber.json`，写明页面要调用哪些应用：`{"apps": ["注册商户数"]}`。页面需要的应用还没有，agent 会顺手写一个提交审核，审核一次以后反复用
3. 运行 `amber page publish ./目录 --name shanghu`，发布到 Amber

第一次发布时，群里出现一张卡片，列出页面会调用的应用，并附上页面首屏的截图。**你点「确认发布」**后页面才生效，卡片上会出现「打开页面」和「私聊我免登录链接」两个按钮。

之后改页面，跟 agent 说要改哪里，它重新发布，**马上生效，不用再确认**，刷新页面就能看到。只有页面要调用的应用变了（`amber.json` 改了），才会再出一张确认卡片。

页面本身不用审核：它只能调用你确认过的那几个应用，而这些应用都审核过，见下面「为什么页面不用审核」。

## 打开页面

- 飞书卡片上点「打开页面」，或者在网站左侧找到页面（挂在它所在的群下面，带「页面」标），点「打开页面」，都会新开一个标签页
- 要先登录 Amber 网站，登录一次能用 7 天。还没登录时，在卡片上点「私聊我免登录链接」：Amber 在你和它的私聊里发一个链接，点开就登录并打开页面。链接 5 分钟内有效、只能用一次，只发给有权限打开这个页面的人，不会出现在群里。也可以私聊 Amber 发「登录」
- 页面里每次查询都以你自己的身份执行：查数仓按你自己的权限出数；会改数据的应用，Amber 会先弹出自己的确认框，你点确认才执行
- 每次调用都会进「最近运行」和审计日志，受运行时限和并发上限约束

## 谁能打开

页面属于创建人。在网站上打开这个页面，「谁能访问」里可以选：

| 选项 | 谁能打开 |
|---|---|
| 仅我（默认） | 只有你自己 |
| 群里所有人 | 页面所在群里的所有人 |
| 指定的群成员 | 你勾选的人 |

每次打开、每次调用都会检查：在名单里，并且现在还在这个群里。退群的人自动失去访问权限。私聊里的页面只有创建人能打开。

**别人通过你的页面调用应用时，以他自己的身份执行**。也就是说，你自己的应用可以借页面给群里指定的人用，不用上架或复制。两类应用要注意：

- **用到密钥的应用**：别人用会用到你的凭证（比如你的 token），所以只有你自己打开页面时能调用，别人调用会被拒绝
- **在执行端环境里运行的应用**：别人会在那个环境里执行，能读到那个环境里的数据。设置访问范围时页面上会提醒

## 为什么页面不用审核

页面在一个隔离的框里运行，放在单独的域名下：

- 不能访问网络，也不能跳转到别的网站、弹出新窗口、加载外部图片
- 只能通过 Amber 调用 `amber.json` 里、并且你确认过的应用，以打开页面的人的身份执行
- 打开飞书文档这类链接要用 `Amber.open`，只能打开网络白名单里的地址（默认是飞书）

所以页面写得怎么样，打开它的人能看到的数据也不会超过他自己能查到的，数据也传不出这个页面。会改数据的操作一定要他本人在 Amber 的确认框里点。

## 给写页面的 agent

在页面里加载 Amber 的接口：

```html
<script src="/sdk/amber-page.js"></script>
```

| 接口 | 作用 |
|---|---|
| `await Amber.run('应用名', { 参数: '值' })` | 调用应用，返回 `{ markdown, blocks, json, runId, elapsedMs }` |
| `await Amber.render(元素, 结果)` | 把结果画成和飞书卡片一样：文字、表格、图表 |
| `await Amber.open(链接)` | 在新标签页打开白名单里的地址（默认是飞书） |
| `await Amber.me()` | `{ name, page }`：打开页面的人的名字和页面名 |
| `Amber.quiet = true` | 不显示 Amber 的「正在执行」提示，由页面自己显示 |

`blocks` 是拆开的输出：`{kind: 'markdown', text}`、`{kind: 'table', data}`（列和行）、`{kind: 'chart', data}`（vega-lite）、`{kind: 'json', data}`。应用可以多输出一个 ` ```json ` 块专门给页面用，页面拿到的 `json` 就是它；飞书卡片和网站上不显示这一块。

限制：

- 文件：最多 200 个、共 10MB；只能是常见的静态文件（html、css、js、json、图片、字体、csv 等），不能有点开头的文件
- 不能从外部 CDN 加载库：要用的库放进目录一起发布。Amber 提供 `/vendor/marked.min.js`、`/vendor/purify.min.js`、`/vendor/vega.min.js`、`/vendor/vega-lite.min.js`、`/vendor/vega-embed.min.js`
- 页面不能直接请求外部接口，数据一律通过 `Amber.run` 拿；可以读目录里自己的文件（比如 `fetch('data.json')`）
- 可以让浏览器下载页面自己生成的文件（比如导出 CSV）

## 删除

创建人或管理员可以在网站上删除页面，链接立即失效，文件一起删除，应用不受影响。
