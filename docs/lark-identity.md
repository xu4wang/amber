# 以你本人的飞书身份运行

有些事只有你本人能做：读你自己的妙记、读你所在群的聊天记录、在你自己的云空间里建文档、查你的日程和邮件。这类应用可以声明「以执行人本人的飞书身份运行」：**谁执行，就以谁的飞书身份**调用飞书（lark-cli 或飞书开放接口），看到的、写下的都是这个人自己有权限的东西。

用之前，每个人要先**授权飞书**一次。

## 能做什么

举几个例子：

| 应用 | 它以你的身份做什么 |
|---|---|
| 拉前采妙记 | 搜索你能看到的妙记，取逐字稿 |
| 群聊日报 | 读你所在群（跳过外部群和免打扰的群）过去 24 小时的消息，交给大模型总结，写进你自己云空间里的一份文档，只有你能看 |
| （示意）我的待办汇总 | 读你的日程、任务，整理成一张表 |

同一个应用，张三执行时读的是张三的群、写进张三的云空间；李四执行时就是李四的。定时任务以**创建定时任务的人**的身份执行。

能用的飞书权限范围，是 Amber 飞书应用开通了的「用户身份权限」（管理员在飞书开放平台开通）。应用具体调用哪些接口、读写什么，都写在代码里，代码经过审核。

## 授权飞书

两种方式，效果一样，是同一份授权：

- **在飞书里**：私聊 Amber 发 `授权飞书`（在群里发也会私聊发给你），点卡片上的「去飞书确认授权」。
- **在网站上**：打开这类应用，页面上方有提示和「授权飞书」按钮。点一下出现「去飞书确认授权」链接和验证码，确认后页面自动变成「已授权」。见[网站操作](web.md)。

确认时要用**你本人的飞书账号**。Amber 会核对确认授权的人是不是发起的人，不是的话这次授权作废。所以授权链接**不要转发给别人**，转发了也没用。

授权之后：

| 想做的事 | 怎么做 |
|---|---|
| 看授权状态 | 私聊 Amber 发 `飞书授权状态`，或在网站上打开这类应用看页面上方的提示 |
| 撤销授权 | 私聊 Amber 发 `撤销飞书授权`。撤销后这类应用由你执行时会被拒绝，你的定时任务也会失败，直到重新授权 |
| 管理员新开了权限 | 已经授权过的人要重新发一次 `授权飞书`，新权限才会生效 |

授权失效（你撤销了，或者过期了）时，执行会被拒绝，Amber 会私聊提醒你重新授权，每天最多提醒一次。

## 把你的操作做成这类应用

和其他应用一样，跟你的 agent 说清楚要以你本人的身份做什么，跑通后存进 Amber：

> 帮我把过去 24 小时我所在群的消息总结成日报，写进我自己云空间的一份飞书文档，发我链接。……存进 Amber，叫「群聊日报」，要以执行人本人的飞书身份运行。

agent 会在应用里声明 `larkUser`，脚本里用执行人的令牌调用 lark-cli（写法见[脚本约定](script.md#以执行人的飞书身份运行)）。提交后在认领卡上试运行：**试运行也以你的身份执行**，所以要先授权飞书。

## 限制

- **只能由人执行**：在飞书、网站上执行，或者定时任务（以创建人的身份）。agent 直接发起的执行不代表任何人，会被拒绝。例外是声明了「结果可以交给 agent」的应用：agent 用 `amber read` 发起，你在私聊卡片上允许后才以你的身份执行，见[读取个人数据](cli-and-skill.md#读取个人数据)。
- **只能在 Amber 本机运行**，不能放进执行端的运行环境。要用机器人的飞书身份时，见[主要场景](scenarios.md)第 6 节。
- **网络只能到飞书**：这类应用不能访问其他网站，也不能开外网。可以同时用 Amber 内置的大模型服务做总结。
- **新开通的权限要重新授权**：管理员给 Amber 的飞书应用新开了权限后，你之前的授权里没有这一项。你执行的应用需要它时，Amber 会私聊提醒你重新发一次「授权飞书」（每天最多一次）。
- **令牌不会出现在结果里**：脚本拿到的是一张短时效的访问令牌，打印出来也会被遮成 `***`；你的长期授权加密保存在 Amber 里，脚本拿不到。

## 审核时看什么

这类应用能以执行人的身份做任何授权范围内的事，所以审核是真正的把关：审核文档会醒目标出「以执行人本人的飞书身份运行」，审核人逐条看脚本以这个人的身份做了什么，尤其是写操作（发消息、改文档、改表格）。见[审核指南](review.md)。

技术细节（令牌怎么保管、怎么核对身份、审计记什么）见[可信身份](identity.md)第 4 节。
