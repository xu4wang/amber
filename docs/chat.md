# Amber 机器人对话

在飞书里，可以私聊 Amber，也可以在群里 @Amber 后发一句话。大多数操作也可以交给自己的 agent 去做（见[和自己的 agent 协作](with-agent.md)）；但凡要**以你的身份**做的事，都要你本人在 Amber 发来的卡片上点一下，这是身份安全的底线，agent 替不了。

## 可以发的话

| 发什么 | 做什么 | 说明 |
|---|---|---|
| `帮助`（或 `应用`、`列表`，旧说法 `指令` 也可以） | 列出这里你能用的应用 | 点「选择」后在表单里填参数执行 |
| `应用名 参数1 参数2` | 直接执行，比如 `天气 上海` | 参数按顺序填；含空格的值用引号括起来。必填参数没给全、或者应用要求执行前确认时，会先弹出表单 |
| `定时任务` | 列出你在这里建的定时任务 | 卡片上可以暂停、恢复、立即运行、删除 |
| `登录` | 把网站登录卡发到你和 Amber 的私聊 | 在群里发也只会私聊发给你，链接 5 分钟内有效、只能用一次 |
| `退出网站` | 让你在所有浏览器里的网站登录都失效 | 怀疑别人用了你的登录时用 |
| `设置密钥 应用名` | 在私聊里发一张填密钥的卡片 | 密钥只能在私聊里填，见[网站操作](web.md)里的「密钥」 |
| `下线 应用名` | 发一张确认卡，确认后下线 | 只有创建人或管理员能下线；确认卡 5 分钟内有效 |

管理员另外还能发：`全局 应用名` / `取消全局 应用名`、`所有应用`（旧说法 `所有指令`）、`执行端`、`撤销执行端 名称`，见[管理员手册](admin.md)。

在群里，你只能看见、执行**自己创建的应用**和全局应用，看不到别人的。

## 会收到的卡片

| 卡片 | 什么时候出现 | 你要做什么 |
|---|---|---|
| **认领卡** | agent 提交了新应用或新版本 | 试运行 → 提交审核；不认识的点「丢弃」。新版本只有原创建人能认领 |
| **表单卡** | 发了「帮助」并选了应用，或执行时参数没给全 | 填参数，点「执行」。标着「需确认」的应用要点红色的「确认执行」 |
| **结果卡** | 执行完 | 表格、图表直接显示在卡片上（每张表最多 100 行，完整内容在网站上看）。结果里写了 `@名字` 的，会真正 @ 到群里的人或机器人 |
| **确认卡** | agent 替你发起了需要你身份的操作（执行、建定时任务、下线等） | 确认是你让它做的，再点。**结果只显示在这张卡上，不会交给 agent** |
| **换绑卡**（私聊） | 你的应用出了新版本，挂在旧版本上的定时任务暂停了 | 点「换绑到新版本」，定时任务就接着跑，时间和参数不变 |
| **接收卡**（私聊） | 有人把应用复制给你，或者管理员把离职同事的应用交给你 | 看清楚再点「接收」：接收后以你的身份执行 |
| **通知卡**（私聊） | 上架结果、Store 里你装的应用出了新版本、定时任务失败或暂停 | 按卡片说明处理 |

## 几条规矩

- **卡片要在原来的群里点。** 群应用、群定时任务的卡片，在别的群里点无效。
- **不是你发起的确认卡不要点。** agent 指明了替谁发起时（通常如此），只有那个人能点；没指明时谁点就以谁的身份执行。
- **不要把密钥发在聊天里**，包括发给 agent。密钥只在你和 Amber 的私聊卡片或网站上填。
- 卡片上写的「你的 agent」，是帮你提交或发起请求的 AI 助手；它没报名字时就这样显示。
