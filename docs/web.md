# 网站操作

飞书里能做的事，网站上大多也能做；另外有几件事只在网站上做：设置配置项、上架到 Store、安装、复制给同事、看历史结果。

## 登录和退出

1. 私聊 Amber（或在群里 @Amber）发「**登录**」。登录卡片只会发到你和 Amber 的**私聊**里，链接不会出现在群里。
2. 点卡片上的「打开 Amber 网站」。这个链接 5 分钟内有效、只能用一次，**不要转发给别人**。
3. 不用时点右上角「退出」。怀疑别人用了你的登录，在飞书私聊 Amber 发「**退出网站**」，所有浏览器里的登录都会失效。

## 左边的列表

| 分组 | 里面是什么 |
|---|---|
| 我的私聊 | 你在和 Amber 的私聊里的应用 |
| 我的群聊 → 某某群 | 你在这个群里的应用、你在这个群里建的定时任务（挂在对应的应用下面），以及你能打开的[页面应用](pages.md)（带「页面」标） |
| 全局应用 | 管理员设为全局的应用，所有人都能用 |
| Amber Store | 上架的应用，可以安装 |
| 最近运行 | 你在所有渠道（飞书、网站、agent、定时）的执行记录 |
| 系统管理 | 只有管理员能看到：执行端、系统设置（运行限制、网络白名单、卡片页脚）、审计日志，见[管理员手册](admin.md) |

列表里只有**你自己的应用**和全局应用。别人建的应用看不到；管理员能看到所有应用，但不能执行别人的。应用名旁边的标签：「已上架」= 你上架到 Store 的原版；「来自 Store」= 从 Store 装的；「需确认」= 执行前要确认。

## 应用页面

选中一个应用，右边上方有三页：

- **执行**：填参数后执行，结果显示在下方。表格显示成表格，折线图、柱状图、饼图显示成图表，并标出数值。标着「执行前需确认」的应用，按钮要点两次。
- **定时**：填时间（可以点常用写法填入）和时区，创建定时任务，以后每次以你的身份执行，结果发到这个群（私聊应用发到你和 Amber 的私聊），没有输出时不发。审核时没有允许定时的应用，这一页会说明原因。
- **代码**：审核通过、实际在运行的代码，第几版、历史版本，以及审核文档链接。

页面下方按情况会出现这些区块：

| 区块 | 什么时候有 | 能做什么 |
|---|---|---|
| **配置项** | 应用有配置项 | 看当前值；创建人（或管理员）可以设置或清除。设置一次，以后每次执行（包括定时任务）自动带上，执行的人不能临时改。必填项没设置时不能执行。值不保密，看得到这个应用的人都能看到。**配置项只能在网站上设置** |
| **密钥** | 应用声明了密钥 | 看是否已设置（只显示末尾 4 位，看不到原值）；创建人（或管理员）可以填写、覆盖、删除。值加密保存，只交给这个应用 |
| **复制给群成员** | 你自己的群应用 | 选一个群成员发送；对方在飞书上接收后，那一份就是他自己的应用。见[应用的分享](sharing.md) |
| **Amber Store** | 可以上架、已上架、从 Store 装的 | 申请上架；看上架状态；装来的应用有新版本时「查看改动」→「升级」 |
| **重新分配** | 管理员看到「创建人已离群」的应用 | 交给群里另一个人，见[管理员手册](admin.md) |
| **管理** | 你是创建人（或管理员） | 下线这个应用。已上架的原版下线时，会问你要不要同时从 Store 下架 |

## 定时任务页面

在列表里点应用下面的 ⏰ 定时任务：可以看到状态、下次运行、上次结果和参数；创建人可以暂停、恢复、立即运行一次、删除。管理员能暂停、恢复、删除别人的定时任务，但不能立即运行。

## Amber Store

左边「Amber Store」里选一个应用，可以看说明、执行时要填什么、需要哪些配置项和密钥、能做什么、完整代码和审核文档。

安装：选装到哪里（你所在、并且 Amber 也在的群，或你和 Amber 的私聊），起个名字，点「安装」。不需要审批。装好后在应用页面里设置配置项和密钥（你自己的），就能用了。

维护人和管理员在应用页面底部还能下架、重新上架；管理员能更换维护人；原版下线后能用「开发模式安装」接着开发。详见[应用的分享](sharing.md)。

## 最近运行

你自己每一次执行的记录：时间、从哪个入口执行的、参数、耗时、成功与否、出错原因，以及当时的完整结果。确认卡上只显示了部分结果的，在这里看全部。
