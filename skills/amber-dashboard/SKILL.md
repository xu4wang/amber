# Amber 报表看板规范

这份规范是硬性要求：做报表类看板时**每一条都要做到**，不要自行放宽，也不要加规范没要求的东西。页面发布、确认、取数这些基础操作见 amber skill 的「做页面应用」。规范会持续补充，以最新版为准。

核心目标：**页面干净整洁，该有的功能都有，不需要的东西一律不加。**

## 一、页面结构

从上到下固定是这几块，没有的就不放：

1. **标题**：页面名称，一行，18px 加粗。旁边不放副标题、说明、标签
2. **筛选栏**：一张白色卡片，横排放全局参数（时间范围、币种、商户类型等）。整页只有这一处全局参数
3. **指标卡组**：一排 4 张（窄屏 2 张），每张写指标名（金额要带币种，如「上账金额（THB）」）、数值（千分位）、较上期变化（涨绿跌红，一位小数）
4. **图表 / 表格模块**：白色卡片，左上角是模块标题（14px 加粗）。同一主题的多个指标用卡片内的页签切换，不要排成一长串卡片；两个模块可以并排（窄屏改成一列）
5. **明细表**：数据多的表格放最后

样式统一：

- 页面背景 `#f5f6f8`，内容最大宽 1200px 居中，左右留白 20px（窄屏 16px）
- 卡片白底、`1px solid #e5e6eb` 边框、圆角 6px、内边距 12px 14px，卡片间距 12px
- 主色 `#3370ff`，正文 13px，次要文字 `#646a73`
- 窄屏（≤900px）布局要能自动换行，不出现横向滚动条

## 二、每个报表模块必须有的通用功能

除筛选栏外，页面上的**每个**报表模块（图表、表格、指标卡组、嵌入的报表）都要接上工具图标：查看的人点模块空白处，模块左侧出现一列图标，同一时间只显示一个模块的图标，点别处收起。图标由 SDK 统一提供，**不要自己画工具栏或常驻按钮**。

| 图标 | 页面自己的模块 | 嵌入的别的报表 |
|---|---|---|
| 点击联动 | `link: true` 时有，查看的人可以关掉这个模块的联动 | 声明了 `receive` / `emit` 时自动有 |
| 打开 | 「单独查看」：模块铺满页面，左上角「返回」 | 「打开原页面」：同一标签页打开，带上当前筛选，左上角「返回」 |
| 导出 Excel | 用 `export()` 的数据，不写就导出模块里的表格 | 被嵌页面的 `Amber.onExport`，不写就导出它的表格 |

接法：

```js
// 页面自己的模块：传模块的容器元素（只画内容的那个元素也行，SDK 会在重画后把图标补回去）
const regionM = Amber.module('#region', {
  title: '按区域上账',
  link: true,                       // 参与点击联动
  onLink: () => draw(),             // 查看的人切换联动开关时重画
  export: () => ({ name: '按区域上账', columns: [{ name: 'r', label: '区域' }, { name: 'v', label: '上账金额（THB）' }], rows }),
});
// 画图时用模块自己的筛选（联动关掉时是 {}），点柱子时发出联动（关掉时不发）
const f = regionM.filter();
bar.onclick = () => regionM.emit({ region: f.region === r ? null : r });

// 嵌入别的报表：amber.json 写 embeds，页面里
await Amber.embed('#rank', 'rank');
```

联动规则：

- 点图表的柱子、扇区、表格的行，就按这个字段筛选所有打开联动的模块；**再点一次同一个元素取消**，不另放「清除筛选」按钮，也不显示「当前筛选：…」这类会出现又消失的提示（会让页面跳动）
- 被点中的元素高亮，其余变浅（透明度约 0.35）
- 可点的元素要让 SDK 认出来，不然点它也会弹出图标：用 `<a>` / `<button>`、设置 `onclick`，或加 `data-amber-action` 属性；用 vega 画的图在点到数据时 `event.preventDefault()`：

```js
view.addEventListener('click', (event, item) => { if (item && item.datum) { event.preventDefault(); m.emit({ region: item.datum.region }); } });
```

## 三、禁止出现的东西

- 说明性文字：操作提示（「点柱子可以筛选」）、数据来源、维护人、口径解释、「演示数据」「仅供参考」
- 装饰：「本页」「嵌入」「主报表」之类标签、图标装饰、多余的分割线和背景色块
- 图表上的多余数字：最大值、合计角标、每根柱子上的数值标签（鼠标悬停看数值即可）
- 常驻的次要按钮：联动、导出、打开、刷新、全屏这类操作只能放在工具图标里
- 编造的数据：没有现成的 Amber 应用就先提交应用，不要在页面里写死示例数据交差

标题、图例（多个系列时）、坐标轴、表头这些读数据必需的保留。

## 四、表格

- 超过 10 行就分页，每页 10 条（明细表可以 20 条）
- 分页器放表格右下角：`‹ 1 2 3 … ›` 加「跳至 [ ] 页」（回车跳转），只有一页时不显示
- 数字列右对齐、千分位，金额带币种；可点的行（会联动的）鼠标悬停高亮
- 不加序号以外的装饰列

## 五、数据

- 数据一律用 `Amber.run('应用名', 参数)` 从审核过的应用拿，页面里不写 SQL、不联网
- 筛选栏参数改了，所有模块一起刷新；模块各自取数，一个失败只在那个模块里显示「加载失败」，不影响别的
- 加载中只在模块里显示浅色占位，不弹窗、不整页遮罩；没有数据显示「暂无数据」
- 数值格式：整数千分位；金额保留到个位（小额可两位小数）；百分比一位小数

## 六、多页面报表（主报表 + 明细）

- 明细报表单独发布成页面，在它的 `amber.json` 写 `embeddable`，主报表用 `embeds` 嵌进来
- 被嵌页面嵌入时不显示自己的标题和参数栏（参数跟随主报表）；单独打开时显示标题和自己的参数栏，用白色卡片包住内容
- 被嵌页面注册顺序：先画页面，最后再调 `Amber.onParams` / `Amber.onFilter`
- 从主报表进明细一律同一标签页打开，左上角只有一个灰色「返回」，不写「返回主报表」

## 七、发布前自查

逐条确认，有一条不满足就改完再发布：

- [ ] 页面结构是「标题 → 筛选栏 → 指标卡 → 图表/表格」，没有多余的块
- [ ] 每个报表模块（筛选栏除外）点空白处都能弹出工具图标，导出的 Excel 有数据
- [ ] 联动：点一下筛选，再点一下取消，页面不跳动
- [ ] 页面上找不到说明性文字、装饰标签、多余数字、常驻次要按钮
- [ ] 超过 10 行的表格有分页和跳页
- [ ] 窄屏下不出现横向滚动条
- [ ] 数据全部来自 Amber 应用

## 八、从 FineBI 迁移

公司计划把 FineBI 报表迁到 Amber。迁移一张报表时：

1. 先拿到原报表：截图、组件清单、每个组件的数据集 SQL 和参数
2. 按下表逐个组件对应，用本规范的样式重做，**不照搬 FineBI 的样式和多余元素**
3. 每个数据集提交成一个 Amber 应用（参数对应 FineBI 的参数控件），审核通过后页面用 `Amber.run` 调用
4. 对应不了的功能先列出来问用户，不要自己发明替代做法

| FineBI | Amber |
|---|---|
| 参数面板 / 过滤组件 | 筛选栏（`Amber.setParams` 传给嵌入的模块） |
| 指标卡 / KPI 组件 | 指标卡组（`Amber.module`） |
| 图表组件 | 图表模块（`Amber.module`，`link: true`） |
| 明细表 / 交叉表 | 分页表格（`Amber.module`） |
| 组件联动 | 点击联动（`m.emit` / `m.filter`，嵌入的用 `emit` / `receive`） |
| 钻取 / 跳转到其他报表 | 嵌入 + 「打开原页面」，同一标签页带筛选打开，左上角「返回」 |
| Tab 组件 | 卡片内页签 |
| 导出 Excel | 工具图标里的「导出 Excel」 |

（迁移中遇到的新组件和对应方式，补充到这张表里。）
